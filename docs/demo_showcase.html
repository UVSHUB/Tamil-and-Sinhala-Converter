SinTam BPO Voice Middleman

The real-time telephony & speech translation bridge for Sri Lankan call centers. Empowers monolingual agents to seamlessly communicate with bilingual customers — converting Sinhala to Tamil and Tamil to Sinhala in live phone calls with sub-second latency.

🏗️ Key Engineering Highlights

🎯 Sri Lankan Persona Tuning

Customized WebSocket system instructions guide Gemini 2.0 to act as a polite Sri Lankan customer support agent, gracefully recognizing Singlish and Tanglish loanwords.

🔇 WebRTC RMS Noise Gate

Configured with an intelligent root-mean-square (RMS) energy threshold (0.025) that completely discards background office chatter, keyboard clatter, and street noise.

⚡ Direct Memory Streaming

Eliminated Docker virtualization bottlenecks. Python FastAPI handles WebSockets directly while serving the bundled Vite React interface with minimal RAM and CPU footprints.
